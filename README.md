# E-commerce Sales Performance Analysis

End-to-end data analysis project for a French online store, built step by step with **Python (pandas)**, **SQL** and **Power BI**.

> 🚧 Work in progress — this project grows as I learn and build each part.

## Business questions

1. How do sales evolve month by month?
2. Which categories and products bring the most revenue?
3. Which cities have the most customers?
4. What is the Average Order Value (AOV)?

## Pipeline

```
Raw CSV (dirty) → Python / pandas (cleaning) → SQL database (analysis) → Power BI (dashboard)
```

## Project structure

| Folder | Content |
|---|---|
| `data/raw/` | Original data, with real-world quality issues |
| `data/clean/` | Cleaned data, ready for analysis |
| `python/` | Data cleaning and exploration with pandas |
| `sql/` | SQL queries answering the business questions |
| `powerbi/` | Power BI report (.pbix) |
| `images/` | Dashboard screenshots |

## Tools

Python · pandas · SQL (SQLite, Snowflake) · Power BI · Power Query · DAX · Git
